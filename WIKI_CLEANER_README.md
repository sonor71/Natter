# NATTER CORE: восстановление качественного корпуса (импортёр 1.4)

Этот патч заменяет только `import_wiki_dump.py`. Не меняет нейросеть, токенизатор,
сохранённые веса, `.bin` и другие категории `data/raw`.

## Проверка на старом дампе без записи

```powershell
cd Y:\NATTER_CORE
.\venv\Scripts\python.exe import_wiki_dump.py --file "downloads/ruwiki_part1.xml.bz2" --max-pages 10000 --rebuild --dry-run
```

`--dry-run` читает и анализирует архив, но не меняет файлы.

## Безопасная пересборка импорта

```powershell
.\venv\Scripts\python.exe import_wiki_dump.py --file "downloads/ruwiki_part1.xml.bz2" --max-pages 10000 --rebuild
```

При `--rebuild` новый набор создаётся **отдельно**, после успешного окончания
старый `data/raw/wikipedia_dump` и каталог метаданных
`data/sources/wikipedia_dump.jsonl` переносятся в `archive/wiki_before_cleanup_<дата>/`.
Иные учебные файлы не затрагиваются. Новые статьи попадают на те же стандартные пути.

Затем:

```powershell
.\venv\Scripts\python.exe prepare.py --dry-run
```

Для продолжения обучения на новых документах запусти `prepare.py` **без**
`--retrain-tokenizer` — старый BPE остаётся неизменным, но train/val набор изменяется.
Качество старого и нового val loss нельзя напрямую сравнивать как одну проверочную выборку.

## Ограничения

- Это эвристическая очистка. Некоторые шаблоны содержат смысловую информацию,
  которую нельзя безопасно восстановить без полного движка MediaWiki.
- Сложные таблицы, формулы, специальные шаблоны и сноски могут удаляться.
- Если обнаружена техническая разметка в итоговом тексте, статья отбрасывается.
- Проверяй случайные файлы вручную и сохраняй ссылку на источник и условия лицензии.
- Действующая задача проекта — обучить модель на качественном русском языке;
  импорт Википедии не означает философских навыков.
