# NATTER: исправление «Получится 1100» на «привет»

## Что случилось

Прежний синтетический датасет содержал тысячи арифметических задач и
заданий на преобразование слов. После ограничения числа повторов
одинакового ответа арифметика с уникальными числами сохранялась лучше
обычных ответов типа «Привет!». Поэтому небольшая модель подхватывала
шаблоны «Получится 1100» даже на бытовые вопросы.

Такое поведение не доказывает работоспособный диалог: смысл вопроса
модель ещё не научилась удерживать.

## Исправленный отдельный эксперимент

Старые `data/dialogues/tiny_ru` и
`checkpoints/dialogue_tiny_ru_*.pt` **не меняются**.

Новый импортёр создаёт `data/dialogues/tiny_chat/`, исключая
большинство численных, арифметических, переводческих, зеркальных
и заимствованных утверждений о личности ассистента.
Это эвристический фильтр, не ручная редактура: качество выборки
всё ещё нужно критически оценивать.

### На компьютере пользователя (Windows, RTX 3080)

```powershell
cd Y:\NATTER_CORE
git pull origin main

# Уже скачанный CSV будет использован повторно.
.\venv\Scripts\python.exe import_dialogues.py --mode conversation

# До запуска посмотри 5 реальных обучающих ответов из вывода.
# Не должно быть "Получится 1100" или "Нужна ещё математика?".

# Отдельные веса от своего pretrain_best.pt (новая SFT серия).
.\venv\Scripts\python.exe train_dialogue.py --dataset tiny-chat --steps 1000

# Строго новая модель, без ошибки выбора старого checkpoint.
.\venv\Scripts\python.exe chat.py --stage tiny-chat --temperature 0.7 --tokens 80
```

Если хочешь сравнить старый SFT, он не удалён:

```powershell
.\venv\Scripts\python.exe chat.py --stage dialogue
```

Обрати внимание: `--stage dialogue` допускает другие файлы
checkpoint и не подходит для строгого сравнения. Используй
`--stage tiny-chat`, чтобы выбрать конкретную новую модель.

### Что такое успех

После обучения проверь хотя бы 10 новых бытовых формулировок и
последовательность из 3–4 связанных реплик, оценив:
1. Отвечает ли Наттер именно на вопрос?
2. Правильно ли использует русский язык?
3. Может ли сохранить контекст? (Пока одношаговый SFT этого не гарантирует.)
4. Не изобретает ли случайные числа или чужую биографию?

Обучение на коротких репликах само по себе **не приведёт**
к философскому мышлению Ницше или Батая. Для этого нужны
связная проза, большие качественные данные, отдельное обучение
аргументации и долговременная память.

Никаких чужих весов и онлайн-инференса не используется.
