# NATTER — первый быстрый этап разговорного обучения

Цель: получить **наблюдаемое улучшение коротких ответов**, а не
имитировать прогресс через val loss и бесконечные статьи Википедии.
Это не готовый философский интеллект, не сознание и не обещание
разговорного уровня современной крупной LLM.

## Откуда берутся диалоги

[GlayAI/Tiny-Russian-Dialogs](https://huggingface.co/datasets/GlayAI/Tiny-Russian-Dialogs)
— текстовый **синтетический** корпус 125 000 русскоязычных пар `q,a`,
лицензия **CC0-1.0** (по карточке поставщика).
Это не чужие веса и не облачный inference API.

Ограничения исходного корпуса: около 13 100 уникальных ответов,
одношаговые диалоги, нет длинной философской аргументации,
часть вопросов звучит искусственно. Качество ответов не гарантируется.

Импортёр:
- сверяет SHA256 официального CSV;
- отбрасывает явный технический мусор и часть чужих утверждений о личности ИИ;
- удаляет дословно дублированные вопросы;
- выбирает **не более трёх разных вопросов на один ответ**;
- разделяет примеры по хешу **ответа**: повторяющиеся ответы не попадают
  одновременно в train и validation;
- сохраняет источник/лицензию в `data/dialogues/tiny_ru/SOURCE.json`;
- НЕ трогает пользовательские `data/dialogues/approved.jsonl`.

Получается значительно меньше 125 000 пар: это намеренно.

## Сначала обновление

```powershell
cd Y:\NATTER_CORE
git pull origin main
```

## Первая загрузка и фильтрация текстов

```powershell
.\venv\Scripts\python.exe import_dialogues.py
```

Тексты сохраняются только на твоём ПК. Если нет доступа к HuggingFace,
скачай CSV вручную с указанной страницы в Downloads и выполни:

```powershell
.\venv\Scripts\python.exe import_dialogues.py --file "Y:\путь\к\Tiny-Russian-Dialogs.csv"
```

Локальный `--file` не проверяет подпись источника автоматически;
сверь SHA256 самостоятельно, если данные получены не из ссылки выше.

## Короткий запуск диалогового обучения

```powershell
.\venv\Scripts\python.exe train_dialogue.py --dataset tiny-ru --steps 500
```

Обучение берёт **собственные** `checkpoints/pretrain_best.pt` и
создаёт ОТДЕЛЬНЫЕ файлы `dialogue_tiny_ru_best.pt` и
`dialogue_tiny_ru_last.pt`. Оно не перезаписывает базовую модель и
не меняет BPE. CUDA AMP задействован, если доступна видеокарта.

После этого:

```powershell
.\venv\Scripts\python.exe chat.py --stage dialogue --temperature 0.7 --tokens 80
```

Попробуй «привет», «как дела», «что такое свобода?».
Сравнивай не только loss, но и содержательность. Короткие синтетические
ответы могут улучшиться, а философские рассуждения всё ещё будут слабыми.

Чтобы продолжить ещё 1000 шагов на тех же файлах:

```powershell
.\venv\Scripts\python.exe train_dialogue.py --dataset tiny-ru --steps 1000
```

Не редактируй train/val JSONL между продолжениями, пока не сохранишь
предыдущий checkpoint: скрипт проверяет хеш датасета.

## Что дальше

Разговорный шаблон — **первый практический результат**, не конечная цель.
Для Наттера, способного рассуждать о Ницше и Батае, следующими будут:
отредактированная русская проза, тщательно отобранные философские тексты,
разнообразная критическая аргументация, многотуровые диалоги и
отдельные задания на понимание с проверенными ответами.
Не пытайся заменить это тысячекратным повторением шаблонных реплик.
